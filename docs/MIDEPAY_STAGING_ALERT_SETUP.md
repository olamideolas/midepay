## What is implemented

`scripts/run_staging_monitor.mjs` collects the fixed read-only aggregate diagnostic using a PostgreSQL connection restricted to the exact staging direct hostname or a Supabase pooler username bound to `ajbhsmcosxgymrtawlmd`. Other projects, connection URL query overrides, other database names and nonstandard ports are rejected. TLS certificate verification stays enabled. Errors are reduced to fixed codes; credentials and server error text are not printed.

The default run is a dry run. Actual sending needs `--send` **and** `MIDEPAY_STAGING_ALERTS_ENABLED=true`. Healthy snapshots send no message. Attention, invalid snapshots or collection failures can produce a text-only warning. The recipient and SMTP host are fixed; no customer identifiers or provider payloads enter the message. Gmail uses TLS on port 465, timeouts, disabled debug logging and a dedicated App Password. SMTP acceptance is reported as `smtp_accepted`, not proof that Gmail delivered it to the inbox. See [Nodemailer SMTP transport documentation](https://nodemailer.com/smtp).

## Secure setup needed

Store the following values privately in the runner's environment or in a protected GitHub environment named `midepay-staging-alerts`. Never paste them into chat, commit them, or put them in frontend/Vercel public variables.

| Name | Value |
|---|---|
| Secret `MIDEPAY_STAGING_DATABASE_URL` | PostgreSQL connection string copied from staging project's Connect dialog, database `postgres`. Use an approved operational account with only the read access required by this diagnostic. Do not use production credentials. |
| Secret `MIDEPAY_ALERT_SMTP_USER` | Gmail account used to send warnings. This can be the selected executive mailbox if that is the account configured. |
| Secret `MIDEPAY_ALERT_SMTP_APP_PASSWORD` | A 16-letter Google App Password generated by that same sender account. The Gmail account password is not an App Password. Spaces in Google's displayed grouping are accepted. |
| Variable `MIDEPAY_STAGING_ALERTS_ENABLED` | Leave unset for dry runs. Set to `true` only for the approved send check. |
